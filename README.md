# User Management API Testing Project

## Descripción
Proyecto de práctica de QA Manual realizado utilizando Postman sobre una API REST pública.
El objetivo del proyecto fue diseñar y ejecutar pruebas funcionales sobre operaciones de gestión de usuarios mediante solicitudes HTTP, verificando consultas, creación, actualización y eliminación de información a través de la API.

## API Probada
Postman Echo API

## Módulo Evaluado
Gestión de Usuarios mediante API

## Alcance de Pruebas

Las pruebas realizadas fueron:
* Consulta de información mediante solicitudes GET.
* Creación de usuarios mediante solicitudes POST.
* Actualización de información mediante solicitudes PUT.
* Eliminación de usuarios mediante solicitudes DELETE.
* Validación de códigos de respuesta HTTP.
* Validación de respuestas en formato JSON.
* Verificación de tiempos de respuesta.
* Verificación de encabezados (Headers) de respuesta.
